**Raj Music** is a beautiful, feature-rich, and fully open-source YouTube Music client for Android. Built with **Jetpack Compose** and **Material 3**, it offers a premium, ad-free music experience with deep system integration.

## ✨ Features

- 🎙️ **Google Assistant Integration**: Control your music with your voice! Try *"Hey Google, play Arijit Singh on Raj Music"*.
- 🚫 **Ad-Free**: No interruptions. Just pure music.
- 🎨 **Dynamic Theme**: Modern Material 3 UI that adapts to your wallpaper colors.
- 📱 **Background Playback**: Keep the music going while you multi-task.
- ⬇️ **Offline Mode**: Cache and download songs to listen anywhere, anytime.
- 🎤 **Synchronized Lyrics**: Real-time lyrics for your favorite songs.
- 🚗 **Android Auto**: Stay entertained safely on the road.
- ⚙️ **Advanced Controls**: Skip silence, audio normalization, and customizable playback speed.

## 🚀 Getting Started

### Download
You can download the latest APK from the **[Releases Page](https://github.com/i-amraj/raj_music_app/releases/latest)**.

### Build from Source
1. Clone the repository:
   ```bash
   git clone https://github.com/i-amraj/raj_music_app.git
   ```
2. Open the project in **Android Studio Hedgehog** or newer.
3. Build the project using the `./gradlew assembleDebug` command.

## 🛠️ Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM
- **Networking**: Ktor / OkHttp
- **Database**: Room
- **Media**: ExoPlayer / Media3
